# 车皮 · 御彩星绘汽车车衣设计工作台

汽车车衣设计工作台，支持轿车、SUV、MPV 构图预览与七个部位的矩形母版编辑、审核和 PSD 导出。包含案例库、账户管理、云端设计历史和管理员后台。

## 运行

需要 Node.js 22.13 或更高版本和 pnpm。项目采用 React、TypeScript、Vinext 和 Cloudflare Worker；账户和云端数据使用 D1、R2。

```bash
pnpm install
pnpm run dev
```

生产构建和本地 Worker 启动：

```bash
pnpm run build
pnpm start
```

账户及云端功能需要配置自己的 D1、R2 和数据库迁移（见 `drizzle/`）；管理员首次开通需要在部署环境设置自己的 `ADMIN_SETUP_KEY`。不要把密钥、用户数据、数据库文件或 `.dev.vars` 提交到仓库。此仓库不包含原站点的数据库和部署身份。

## 功能与边界

- 单海报参考、快速/专业参数、配置预览、七部位编辑与审核；可导出 PSD 和 PNG。
- 案例支持上传、收藏、文字标签和人工修改，登录后可主动上传云端供管理员审核。
- 支持个人账户、手动保存和读取云端历史；管理员可管理账户、云端历史、案例和部分设计设置。
- AI 生图、图片自动分析与自动打标签、AI 分层和背景补绘需要接入模型服务。当前可生成任务说明并手动回填素材，不能当作已接入自动生图。
- 车型预览用于构图参考；PSD 是按比例制作的分层设计稿，需设计师进一步进行实际车型适配与 150 DPI 印刷制作。

## 扣子编程接入

导入仓库后，请先识别当前 Vinext/Cloudflare Worker 架构及 D1/R2 依赖，再根据扣子编程实际支持的运行环境适配账户、数据库和文件存储。生图、分析、自动标签与重生成需要接入平台实际提供的模型接口；保持任务状态、错误提示和手动回填流程，不要以示例图冒充生成结果。平台接口和部署方式需要在目标环境实际验证。
